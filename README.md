## Sobre la aplicación

**Swipe Cleaner** (`com.smartcleaner.app`) es una app de limpieza de archivos multimedia para Android que:

- Escanea el dispositivo para detectar **imágenes y videos de gran tamaño o duplicados**.
- Permite al usuario **eliminar o comprimir** archivos de forma manual (nunca automática).
- Mueve los archivos borrados a una **papelera interna** antes de la eliminación permanente, permitiendo restaurarlos.
- Muestra **anuncios recompensados** a través de Google AdMob.

## Resumen de la Política de Privacidad

### Datos que se recopilan

| Categoría | Compartido con terceros |
|-----------|------------------------|
| Metadatos de archivos (nombre, tamaño, fecha) | No |
| Información del dispositivo (modelo, versión Android, idioma) | No |
| Datos de uso de la app (acciones realizadas) | No |
| Identificador publicitario de Android (GAID) | Sí – Google AdMob |

**No se recopila**: nombre, correo electrónico, teléfono, ubicación GPS, contactos, micrófono, cámara ni datos biométricos.

### Permisos Android

- **READ / WRITE EXTERNAL STORAGE** – Para escanear y gestionar imágenes y videos.
- **INTERNET** – Para cargar anuncios de Google AdMob.

### Servicios de terceros

- **Google AdMob** – Publicidad recompensada. Rige la [Política de Privacidad de Google](https://policies.google.com/privacy).

### Privacidad de menores

La app está disponible para el público en general, incluidos menores de 13 años, y cumple con las directrices de Google Play para contenido apto para todas las edades.
